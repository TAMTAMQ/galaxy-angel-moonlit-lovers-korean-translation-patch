## 신규 발견 — 리터럴 `\` 문자가 화면에 그대로 나오는 결함 27건 (수정 완료)

파일을 계속 육안으로 대조하던 중 `SCENARIO_DAT_00012800:dialogue:0265`에서
`정도네요～\.` 처럼 **역슬래시(`\`)가 문자 그대로** 번역문에 섞여 있는 것을 발견했다.
갤럭시 엔젤 검수 때 나온 "리터럴 `\n`이 화면에 그대로 나온다"(C0)와 같은 계열의
결함이라 판단해, 25,510 유닛 전체에서 번역문에 역슬래시 문자가 있는지 전수 스캔했다.

**27건**이 나왔고 두 가지 패턴이었다.

1. **문장 끝에 리터럴 `\n`(역슬래시+n, 실제 줄바꿈이 아님)이 붙어 있는 경우 — 19건.**
   `SCENARIO_DAT_000d2800:dialogue:0631~0639`(9건)과
   `SCENARIO_DAT_00109800:dialogue:0141~0150`(10건), 두 연속 구간에 몰려 있었다 —
   갤럭시 엔젤 C0의 "한 번의 잘못된 번역 패스로 보인다"는 진단과 정확히 같은 패턴이다.
   예: `'앗, 노아가 없어!?\\n\n'` (뒤의 `\n`은 정상 종료 개행, 앞의 `\\n`이 화면에 그대로
   나오는 문제 문자). 전부 뒤의 리터럴 `\n`만 제거했다.
2. **문장 중간에 역슬래시 한 글자가 낱말 경계나 공백 자리에 잘못 들어간 경우 — 8건.**
   예: `'커, 커플룩?\\ 네 옷을 고르고 있던 게...'` → `'커, 커플룩? 네 옷을 고르고 있던 게...'`.
   문맥상 원문의 줄바꿈이 있던 자리에 리플로우 과정에서 역슬래시가 잘못 남은 것으로
   보인다. 해당 자리의 공백/개행 구조를 그대로 두고 역슬래시만 제거했다.

수정 후 25,510 유닛 전체에서 역슬래시 문자 잔존 **0건**을 재확인했다.

- **「君」(2인칭)을 존칭 접미사 "-군"으로 오역**하는 패턴이 최소 2곳에서 발견됨 — 기계
  번역이 문맥 없이 음이 같은 한국어 형태소로 오인한 것으로 보인다.
- **한국어 줄임표(`……`) 대신 ASCII 점 3개(`...`)가 섞여 쓰인 사례**가 다수 발견됨.
- **관용구 「うわさをすれば」(호랑이도 제 말 하면 온다더니)**가 서로 다른 파일에서 반복적으로
  단순 직역("소문이 돌고 있더니")되어 있었다.

## 남은 작업 범위

- 기계적으로 검사 가능한 항목(구조·표기·표시 폭)과 25,510유닛 전체 육안 대조는 이번
  세션으로 완료되었으므로, 추가로 필요한 작업은 실기(실제 게임 화면)에서의 검증
  (`image-render-verify-side-by-side` 원칙 참고) 정도로 좁혀진다.

  대조)은 재검수 시 다시 볼 필요 없다.
