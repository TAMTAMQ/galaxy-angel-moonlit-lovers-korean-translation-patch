# 갤럭시 엔젤 문릿 러버즈 번역 용어집

번역기가 읽는 확정 표기는 `glossary.tsv`에 있다.

## 기준

- 1편 `work/galaxy_angel`에서 사용자와 확정한 표기를 그대로 승계한다. 시리즈 2편이므로
  같은 인물·함선·메카는 반드시 같은 표기여야 한다.
- 승계 대상 중 **이 게임 원문에 한 번도 나오지 않는 항목은 뺐다** (`クリオム` 등).
  빈도·붙는 호칭·겹치는 표기는 전부 이 게임 코퍼스(대사 25,510단위)에서 다시 셌다.
- 본작 신규 고유명사는 2026-08-28 세션에서 사용자가 확정했다.
- `・`가 들어간 원문은 번역에서도 같은 위치에 `・`를 유지한다.
- `ミルフィーユ`는 `밀피유`, 작중 애칭 `ミルフィー`는 `밀피`로 구분한다.
- `エンジェル隊`는 일반 표면형 `엔젤대`, 정식 부대명 `ムーンエンジェル`은 `문 엔젤대`로 구분한다.

## 번역기 적용 규칙

1. 긴 원문 표기부터 매칭한다. `烏丸ちとせ`를 `ちとせ`보다, `タクト・マイヤーズ`를
   `タクト`보다 먼저 본다. `glossary.tsv`는 원문 길이 내림차순으로 정렬돼 있다.
2. 원문에 전체 이름이 없으면 번역에도 성을 임의로 추가하지 않는다.
3. 원문에 호칭이 있을 때만 한국어 호칭을 붙인다.
4. RA 계열 명칭은 이 작품의 용어집에 새로 추가하지 않는다.
5. 확정 표기를 바꿀 때는 번역 전체의 조사와 새 한글 글리프 수를 다시 검사한다.

## 재생성

```
python tools/moonlit_lovers_build_glossary.py
```

1편 `glossary.tsv` + 이 게임 코퍼스에서 `glossary.tsv`를 다시 만든다. 신규 표기는
스크립트 안 `NEW_ROWS`에 있다.
