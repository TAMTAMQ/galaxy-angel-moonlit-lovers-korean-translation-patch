## v0.4.8 전투 대사 정렬·이미지 보존 및 저장 제목 안정화

- 원문 1줄과 빈 2행으로 구성된 전투 대사도 재배치 대상에 포함했습니다. 긴 번역은 최대 3줄까지 사용하며, 같은 유형의 메시지 전체를 점검했습니다.
- 시리즈 공통 용어를 **쿵후 파이터**로 통일했습니다. 대사·용어집·기체명 이미지·전투 결과표와 관련 복사본에 반영했습니다.
- 이미지 슬롯 용량이 부족하더라도 수동 편집 이미지를 축소하거나 추가 색상 축약하지 않도록 빌드 보호를 강화했습니다. 전투 UI 복사본 967개에서 권위 이미지 기준 픽셀 불일치가 없음을 확인했습니다.
- 불필요한 빈 ASS와 대응 자막용 PSS를 제거했습니다. 실제 자막이 있는 영상 22개는 현재 권위 PSS를 보존했고, 제외 영상 5개는 일본판 원본과 일치합니다.
- 저장 제목의 반각 공백을 2바이트 문자 시작으로 오인하던 판별을 수정했습니다. 24바이트 복사 경로에서도 문자 중간 잘림을 방지하고, 한글 코드 배치를 고정했습니다.

### 세이브와 진행 불가 안내

프리징은 관련 원인 수정 후 개선된 것으로 보이지만, 모든 경로에서 완전히 해결됐다고 확정할 수는 없습니다. 향후 같은 증상이 다시 제보되면 당시 세이브와 실행 환경을 기준으로 재확인하겠습니다.

기존 세이브/세이브스테이트의 제목은 이전 문자 코드를 그대로 이어받을 수 있으며, 자동 변환은 포함하지 않았습니다. 원본 메모리카드를 백업해 주세요. BGM 백색 소음은 해결됐다고 확인하지 못한 별도 항목입니다.

### 검증과 상세 내역

일본판 원본에 배포 xdelta를 다시 적용하여 검증 ISO의 SHA-256과 일치하는지 확인한 뒤 배포합니다. ISO 자체는 배포하지 않습니다. 원본과 결과 ISO 및 패치 해시는 첨부한 `README.txt`, `SHA256SUMS.txt`에 있습니다.

항목별 변경 전후와 유지 사유는 [후속 검수 기록](https://github.com/TAMTAMQ/galaxy-angel-moonlit-lovers-korean-translation-patch/blob/v0.4.8/ISSUE_1_FOLLOWUP_20261018.md), [저장 제목 수정 기록](https://github.com/TAMTAMQ/galaxy-angel-moonlit-lovers-korean-translation-patch/blob/v0.4.8/SAVE_TITLE_FIX_20261019.md)을 참고해 주세요. 이 릴리즈 안내가 앞선 기록의 '로컬 ISO만 생성' 상태를 대체합니다.
